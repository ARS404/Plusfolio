# Plusfolio 1.0.6

Выпуск от 17.11.2026, тег `v1.0.6`. [История изменений](../../CHANGELOG.md), [результаты локальных проверок](1.0.6-checks.json).

## Аналитика

- В шапке кружка появились «Аналитика кружка» и «Мои результаты в кружке» в зависимости от прав. В отчёте уже выбран кружок, фильтр можно изменить или сбросить.
- В групповой аналитике гистограмма строится по доле решённых задач каждого школьника. Доступен шаг 5, 10 и 25 процентных пунктов, по умолчанию 10. Верхние границы подписаны на шкале, ровно 0% и 100% вынесены отдельно. Число показывается над выбранным столбцом.
- Выбор столбца показывает число и долю школьников в диапазоне. Список раскрывается под графиком и содержит прогресс каждого школьника и ссылки на доступные профили. При одном выбранном кружке он подставляется в отчёт школьника.

В `/api/v1` у строк `student_rows` добавлено поле `can_view_profile`. Формат и границы поля `distribution` сохранены. Школьнику доступна личная аналитика в пределах его прав.

## Обновление с 1.0.5

Последняя миграция остаётся `0019_issue_edit_version`. Схема БД и зависимости прежние. Штатный `update` делает свежую резервную копию и запускает существующую инициализацию. Ручной перенос данных и очистка TeX-кэша не требуются. На проверенных ресурсах Tectonic контракт пакета совпадает с 1.0.5.

В папке установленного экземпляра выполните:

```bash
git fetch origin tag v1.0.6
git switch --detach v1.0.6
python3 scripts/server.py update
python3 scripts/server.py version
python3 scripts/server.py check-public
```

При установке из готовых образов передайте `--release /путь/images-1.0.6.json` с проверенным манифестом для вашей архитектуры. После обновления проверьте версию `1.0.6`, переход из кружка в отчёт, сброс фильтра, выбор столбца и переход из списка в профиль. Под ролью школьника проверьте личный отчёт по тому же кружку. Восстановление при сбое описано в [серверном руководстве](../server-deploy.md#восстановление).

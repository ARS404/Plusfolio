# Интерфейс Plusfolio

После входа пользователь видит список доступных кружков. Внутри кружка основная рабочая задача — быстро отметить решение школьника или разбор задачи. Визуальное направление: спокойный рабочий журнал с хорошей типографикой, устойчивой таблицей и минимумом декоративных элементов.

Документ описывает целевые экраны. Первый рабочий интерфейс уже есть в локальной демке; подробный редизайн можно сделать после проверки механики. Отличия демки — в [этапах выпуска](release-roadmap.md).

## Навигация по ролям

| Роль | Основные разделы | Экран после входа |
| --- | --- | --- |
| Учитель | Мои кружки, задачи, листки, приглашения | Список своих кружков |
| Школьник | Мои кружки, мои задачи, мои результаты | Список своих кружков |
| Аналитик | Кружки, отчёты, приглашения | Список кружков по разрешённым тегам |
| Администратор | Все кружки, задачи, листки, пользователи, дерево тем, три справочника тегов, приглашения, аудит | Список всех кружков |

Слева на широком экране — компактная навигация; сверху — название текущего раздела и профиль. В кружке вкладки: «Журнал», «Листки», «Школьники», «О кружке». Преподаватели и теги находятся в настройках «О кружке» с учётом прав.

В «О кружке» показывается список преподавателей, в том числе несколько действующих одновременно. Каждый работает с одним общим журналом и составом; у изменения отображается фактический автор в пределах разрешённого аудита.

Действия определяются объединением ролей и текущим кружком, сервер всегда проверяет права. Совмещение учителя и аналитика уже поддерживается без ручного рабочего переключателя. Кнопки демо-профилей переключают вымышленные аккаунты исключительно в локальном режиме.

## Главная и пустой кружок

Главная показывает доступные кружки с названием, городом/регионом и числом участников. У администратора есть действие «Создать кружок»; у преподавателя в текущей версии его нет. Пустой список и пустой кружок — нормальные состояния.

Администратор создаёт кружок и приглашает преподавателя. Внутри пустого кружка преподавателю доступны «Пригласить школьников» и «Добавить по email». Для зарегистрированного школьника повторное принятие инвайта не требуется; удаление по email закрывает участие только в этом кружке.

В списке школьников и строках журнала показывается вычисленный текущий класс. В списке также виден год выпуска. Преподаватели и администратор открывают «Класс школьника» кнопкой рядом с участником и указывают ожидаемый год окончания 11-го класса; поле можно очистить. Пока год не указан, показывается «Класс не указан». Автоматический переход происходит 1 сентября, после 11-го класса — «Выпускник», до первого — «Ещё не учится».

## Журнал внутри кружка

```text
Plusfolio       Мои кружки / Кружок А                       Профиль

Мои кружки      Кружок А              7 класс · город · регион
Задачи          Журнал | Листки | Школьники | О кружке
Листки
Приглашения     Листок: Инварианты ▾    Выдан: 21.10.2026
                Найти школьника…       Только нерешённые □

                Школьник          1      2      3      4     Решено
                Разобрана         ✓      —      ✓      —
                Участник 01       +      ·      +      ·       2/4
                Участник 02       ·      +      +      +       3/4
                Участник 03       +      ·      ·      ·       1/4

                + Решена    · Не решена    ✓ Разобрана
                Отметки решений общие для всех кружков школьника
                Все изменения сохранены
```

Имена в схеме условные. В интерфейсе показывается отображаемое имя из карточки школьника.

Школьники — строки, задачи — столбцы. Первый столбец и заголовки закреплены при прокрутке. У каждой задачи доступна карточка с условием; преподаватель читает решение, школьник — если показ явно включён для разобранной задачи в этом кружке. Заголовок содержит номер в листке, а подсказка — название и постоянный ID задачи, чтобы не путать одинаковые номера из разных листков.

### Как ставятся отметки

- Один клик или Space в ячейке переключает решённость; повторный снимает отметку.
- Стрелки перемещают фокус между ячейками. Enter открывает подробности выбранной отметки.
- Нажатие на заголовок задачи открывает условие в боковой панели, сохраняя положение в журнале.
- Строка «Разобрана» меняется независимо и подписана «для этого кружка».
- У снятия существующей отметки доступно «Отменить». Если запись уже изменил другой преподаватель, автоматическая отмена запрещена, показываются новые данные.
- Первое изменение глобальной отметки сопровождается пояснением: «Результат обновится во всех кружках школьника». Постоянная короткая подпись остаётся под журналом.
- В подробностях: текущий результат, время подтверждения и доступная история. Сведения об источнике из чужого кружка заменены нейтральным «Отмечено в другом кружке».

Каждое изменение имеет состояния «Сохраняется», «Сохранено», «Не сохранено». При потере сети журнал не выдаёт локальную отметку за сохранённую. Офлайн-редактирование откладывается: оно потребует очереди изменений и разрешения конфликтов.

На первом этапе без массового заполнения всего столбца: ошибка одним нажатием затронет много школьников. Позже массовая операция может показывать точное количество изменений и требовать подтверждение состава.

### Большие группы и телефоны

На широком экране сохраняется матрица с горизонтальной прокруткой задач; длинный листок можно ограничить диапазоном номеров. При большом составе используются поиск, фильтры и постраничная загрузка школьников.

На телефоне предлагаются два режима: «по школьнику» и «по задаче». В первом преподаватель выбирает школьника и видит список задач с крупными переключателями; во втором — задачу и список школьников. Полная таблица доступна дополнительным режимом. Кнопки рассчитаны на касание, смысл статусов не зависит от цвета.

## Банк задач

```text
Задачи                                      Создать задачу
Поиск по названию, условию или ID…
Теги ▾    Мои / Все ▾    Черновики / Опубликовано ▾

P-014  Чётность суммы              чётность · инварианты
Краткое описание…                 Автор · Опубликована

P-028  Раскраска доски             раскраски · комбинаторика
Краткое описание…                 Автор · Черновик
```

Карточка задачи содержит название, описание, одну или несколько тем из общего дерева, теги, условие и отдельную область решения. Редактор — текст с Markdown и формулами LaTeX плюс предпросмотр; ошибка формулы показывается рядом с конкретным фрагментом.

Действия: «Добавить в листок», «Создать копию», «Редактировать черновик». Опубликованная задача неизменяема; любое исправление создаёт новую задачу с новым ID, старые отметки к ней не переносятся. Учитель выбирает только готовые теги из справочника задач; управление самим справочником доступно администратору.

У школьника есть «Мои задачи»: задачи, фактически полученные через персональные назначения, без дублей; рядом вкладка всех полученных листков с кружком, датой и номером каждой выдачи. Доступны поиск и теги соответствующего типа. Общий банк и дерево тем в навигации школьника отсутствуют. История полученных материалов сохраняется после выбытия, но доступ к закрытым решениям пересчитывается по текущим кружкам.

В банке задач и листков добавляется фильтр «Темы»: раскрываемое дерево, поиск по названию/пути и выбор нескольких узлов. По умолчанию выбранная ветка включает подтемы; доступен режим прямой привязки. Карточка показывает путь к выбранным темам. Результаты и счётчики учитывают права пользователя и не дублируют материал при пересечении веток. Дерево и правила выбора описаны в [темах](topics.md).

В каждом разделе последним пунктом отображается «Прочее». При поиске и в выбранных значениях показывается полный путь, например «Геометрия → Планиметрия → Прочее». Это конечная тема: у неё нет раскрытия вложенного дерева.

## Листок

Редактор черновика показывает название, описание, несколько тем из общего с задачами дерева, теги из отдельного справочника листков и пронумерованные задачи. Темы листка выбираются независимо от тем его задач. Задачи можно добавить из банка, убрать и переставить. Для первой версии достаточно перемещения кнопками «выше/ниже» с клавиатуры; перетаскивание может быть дополнительным способом.

Панель справа показывает итоговый порядок и состояние публикации. Пустой листок или материал без темы сохраняется как черновик, но не публикуется и не выдаётся. Номер задачи относится к этому листку; ID относится к задаче во всём сервисе.

«Выдать в кружок» открывает выбор доступного для редактирования кружка и даты. Перед подтверждением показываются название листка, число задач и кружок. Повторная выдача уже выданного листка ведёт к существующей записи. Будущая дата в MVP запрещена: отложенная публикация пока не проектируется.

После публикации листок неизменяем, даже если ещё не выдавался. Исправление задачи требует новой задачи и нового листка; изменение набора или порядка задач — копии листка. История прежних выдач сохраняется. Новичок автоматически получает все прежние листки кружка при вступлении, без повторной выдачи кружку.

## Карточка школьника

Учитель видит карточку в контексте своего кружка: отображаемое имя, период участия, выданные задачи, общий статус этих задач и сводку по темам. Чужие кружки, их состав и их закрытые материалы через карточку не раскрываются.

У школьника есть личный раздел «Мои результаты»: уникальные решённые задачи и прогресс по своим кружкам. Одна и та же задача может присутствовать в двух листках, но в общем портфолио считается один раз. Условие доступно в собственной истории. В «Моих задачах» и персональных PDF решение видно, если задача разобрана и показ решения включён хотя бы в одном действующем кружке школьника. Отзыв участия или показа закрывает решение при следующем запросе.

Существующего школьника преподаватель добавляет по точному email регистрации без нового подтверждения со стороны ребёнка. Если аккаунта ещё нет, отправляет инвайт; участник появляется после принятия. Для добавления по ФИО зарегистрированные школьники ищутся только внутри операции выбранного кружка, доступной его редактору. Подсказки содержат ФИО, класс, год выпуска и замаскированный email для различения совпадений; полный email через поиск не возвращается. Выбытие закрывает текущий период участия и сохраняет историю.

## Обзор аналитика

Отчёты открываются отдельным разделом после главного списка кружков. Верхняя часть — область доступа: «Кружки с тегами …». Ниже фильтры периода назначения школьникам, региона, города, тем задач/листков, тегов соответствующего типа и кружка. Рабочая область содержит небольшую сводку и таблицу кружков с числом школьников, выданных задач, разобранных задач и процентом закрытия.

Из строки можно открыть журнал кружка для чтения. Над показателями подписано «Текущее состояние задач, назначенных школьникам за период». Экспорт повторяет выбранные фильтры и не добавляет скрытых персональных полей.

Пустой срез объясняет причину: нет доступных кружков, нет выдач в периоде либо фильтры исключили все данные. Значение «нет данных» визуально отличается от нуля.

## Приглашения и вход

Форма обычного приглашения: email → допустимая роль → область доступа → итоговая сводка. У аналитика выбор роли ограничен учителем и школьником, у учителя — школьником. Для преподавателя и школьника можно выбрать несколько существующих кружков; для каждого создаётся отдельное приглашение с той же ролью. Для аналитика выбираются теги из справочника кружков. Добавление администратора выделено в отдельное действие, доступное только администратору.

Из кружка преподаватель вводит один или несколько email. Зарегистрированного школьника можно добавить напрямую; для нового адреса формируется приглашение. Пакет отправляет отдельное письмо каждому адресату. Список показывает роль, кружок, состояние инвайта и доставки, срок, повторную отправку и отзыв.

Новый получатель видит, кто и куда пригласил, и задаёт пароль. Если к моменту принятия он уже зарегистрирован, сервис предлагает войти; пароль повторно не задаётся, профиль не дублируется. После явного принятия роль из инвайта добавляется к прежним ролям аккаунта.

Состояния ссылки: приглашение действительно, срок истёк, отозвано, уже использовано. Ссылка не активируется простым открытием: это важно и для случайных переходов, и для почтовых сканеров.

## Визуальное направление

| Элемент | Предложение |
| --- | --- |
| Образ | Рабочая тетрадь и журнал: спокойная сетка, ясные номера, свободное пространство вокруг условия |
| Бренд | Plusfolio; знак «+» связан с подтверждённым решением |
| Основа | Светлый фон `#F6F8FA`, белые рабочие поверхности, тёмный текст `#172C3D` |
| Главное действие | Синий `#2563EB`; один главный призыв на экран |
| Статусы | Решена — плюс и зелёный акцент; разобрана — галочка и отдельная подпись; ошибка — текст и красный акцент |
| Типографика | Системный шрифт с кириллицей, табличные цифры в журнале; математический набор для формул |
| Плотность | Компактный журнал, более свободные страницы условий и форм |
| Доступность | Видимый фокус, подписи полей, управление клавиатурой, символы кроме цвета; контраст проверяется на макетах |

Тёмная тема, анимации и иллюстрации вторичны. Первые визуальные макеты стоит сделать для журнала на широком экране, мобильной отметки по школьнику и редактора задачи с формулами.

## Состояния, которые нужны в макетах

Новый кружок без школьников; кружок без листков; пустой поиск; слишком длинное условие; задача с ошибкой формулы; ожидающее приглашение школьника; выбывший школьник; роль только для чтения; истёкшая сессия; потеря сети при сохранении; конфликт версий; отозванный доступ; использованная ссылка приглашения; ошибка доставки письма.

В режиме чтения таблица не выглядит редактируемой. В форме с несохранённым черновиком переход предупреждает о потере текста. При копировании опубликованного материала явно показано, что создаётся новый объект; исходный материал и его выдачи сохраняются.

## Видимость для школьника

В журнале текущего кружка школьник читает условия и отметки сдачи всех участников. Все переключатели заблокированы. Решение есть в ответе только при включённом преподавателем показе разобранной задачи в этом кружке. В аналитике — только собственные результаты, в том числе из личной истории после выбытия. Групповые проценты и отчёты других детей через этот раздел не показываются.

В локальной демке на телефоне пока используется таблица с горизонтальной прокруткой и закреплённой колонкой имён. Отдельные режимы «по школьнику» и «по задаче», расширенный редактор черновиков и массовая рассылка относятся к следующим итерациям.

## Текущий журнал по нескольким листкам

Над таблицей — переключатель «Выбранные / Все листки» и общий список с галочками. Он позволяет показать один, несколько или все выданные листки; по умолчанию открыты все. Снятие всех галочек в режиме выбора оставляет журнал пустым и выключает выгрузку. Общая матрица имеет два уровня заголовков: листок и дата, затем его задачи. Нумерация начинается заново внутри каждого блока. Одинаковые задачи в разных блоках показывают одну отметку решения.

Кнопка «Выгрузить» и список форматов находятся над журналом. По умолчанию Excel, альтернативно TSV. Выгрузка соответствует выбранным листкам и поиску школьника. При пустом выборе предлагается выбрать листки; случайная выгрузка всего кружка вместо пустого выбора не выполняется.

В плюснике у редакторов под строкой разбора есть строка «Показать решение» с галочкой для каждой задачи. До разбора галочка заблокирована и объясняет причину подсказкой. Включённый показ отмечается подписью «Решение открыто» под номером задачи. Школьник по клику получает условие и раскрытое решение; скрытые решения по-прежнему не передаются. Снятие разбора выключает показ во всех блоках этой задачи.


## Фильтры выбора

Город доступен на главной и во всех списках выбора кружка: аналитика и приглашение. Список городов строится из доступных пользователю кружков. Можно выбрать несколько городов; пустой выбор означает все доступные города. В аналитике смена городов сохраняет выбранные кружки, которые подходят новому срезу. В форме приглашения города только сужают список: ранее выбранные кружки сохраняются и видны отдельными кнопками.

У задач и листков есть фильтр по тегам своего типа. Он работает в библиотеке, при выборе задач для нового листка, при выдаче листка, в списке выданных листков и в журнале. Поиск и тема сочетаются с тегом. Темы остаются содержательным деревом без собственных тегов и фильтра тегов.

В составлении листка смена фильтра сохраняет уже выбранные задачи и их порядок; их можно убрать из видимого списка выбранного независимо от фильтра. В форме выдачи тоже можно выбрать несколько листков; фильтры сохраняют выбор. Уже выданные и архивные листки скрыты. Сервер выдаёт весь набор одной датой и откатывает операцию целиком при любой ошибке. Поиск и тег применяются сервером до ограничения списка материалов в 300 записей.

В журнале режимы выбранных и всех листков работают по текущему фильтру тегов листков. Экран и Excel/TSV получают один и тот же явный набор ID выдач; фильтр не меняет состав опубликованных листков, отметки и назначения. При отсутствии подходящих листков есть отдельное пустое состояние и сброс тега.


Аналитика расширена обзором и вкладками «Задачи», «Листки», «Темы», «Школьники», «Кружки». Обзор показывает назначенный объём, общее закрытие, полные листки, распределение и медиану прогресса, состояние разбора и задачи, к которым можно вернуться. Нажатие на раздел диаграммы фильтрует отчёт по теме. В таблицах есть поиск, сортировка и пагинация; фильтры сохраняются при переключении вкладок. Личные отчёты скрывают групповое распределение и именные таблицы.


Раздел «Теги» доступен в меню администратора. В нём три отдельных вкладки: задачи, листки и кружки. Действие «Добавить тег» создаёт тег в открытом справочнике; название обязательно, до 100 символов и уникально внутри справочника. Создание записывается в аудит. Преподаватели, аналитики и школьники не могут создавать теги через интерфейс или API. Созданный тег сразу доступен в соответствующих формах и фильтрах.


В аналитике «Темы задач» — раскрываемое дерево с множественным выбором. Можно отмечать несколько независимых узлов; выбранная ветка включает сам узел и всех потомков. При выборе родителя отдельные выбранные потомки заменяются им. Вложенные галочки включены автоматически и заблокированы до снятия выбора родителя; частично выбранные ветки отображаются промежуточным состоянием. Выбранные ветки видны отдельными кнопками под полем, их можно убрать по одной или сбросить все. Пустой выбор означает все темы. Поиск раскрывает совпадения с сохранением пути в дереве; «Прочее» остаётся последним в своём разделе. Исторические архивные темы тоже доступны в фильтре.


## Общий множественный выбор

Города, кружки в аналитике и приглашениях, теги задач/листков во всех фильтрах и листки для выдачи поддерживают несколько значений. Общий компонент показывает галочки, поиск, «Выбрать видимые», сброс и кнопки выбранных значений с удалением по одному. Поиск не снимает выбор. Пустой фильтр означает все значения; пустая форма выдачи/приглашения требует выбрать хотя бы одну запись. Внутри одного фильтра действует «или», между фильтрами — «и».

Дерево нескольких тем используется в аналитике и обеих библиотеках, с автоматическим включением потомков. Формы материалов уже поддерживают несколько прямых тематических привязок; выбранные темы листка не меняют темы его задач. Роли аккаунта и готовые теги в формах сохраняют множественные галочки. Формат файла, порядок сортировки, роль одного приглашения и родитель темы сохраняют единственное значение по смыслу поля.

При приглашении сразу в несколько кружков на каждый создаётся отдельная ссылка и отдельное локальное письмо. Все выбранные области проверяются; ошибка в любой откатывает новые приглашения, отзыв старых ссылок, письма и аудит всего набора. Пакетная выдача листков так же атомарна и не разрешает повторную выдачу листка кружку. Повторяющиеся ID в одном наборе удаляются; пустые и некорректные ID отвергаются до записи.


## Личный кабинет локальной демки

Раздел `#/account` доступен каждому вошедшему пользователю из меню «Личный кабинет» и по имени/аватару внизу слева. Переключение вымышленных аккаунтов вынесено в отдельную кнопку «Демо-профили»; обычный кабинет и выход доступны также вне режима демо.

Сверху — имя, email регистрации и все роли аккаунта. В основной колонке показываются блоки каждой назначенной роли:

- Школьник: собственные уникальные назначенные и решённые задачи, процент прогресса, остаток, активные кружки, текущий класс и год выпуска. Результаты сохраняют личную историю после выхода; совмещение ролей не добавляет чужие результаты в личную сводку.
- Преподаватель: активные кружки, в которых он преподаёт, уникальные текущие участники, число выдач листков, количество созданных задач и листков, переходы к отчётам, приглашениям и банку.
- Аналитик: назначенные теги доступа, активные кружки и города в своей аналитической области. Преподавательские права совмещённого аккаунта не увеличивают область именно аналитического блока.
- Администратор: число активных кружков/аккаунтов и опубликованных материалов, переходы к пользователям, тегам и приглашениям.

Ниже — первые восемь доступных кружков с городом, архивным состоянием и отношением пользователя к кружку; полный список открывается отдельной ссылкой. Чужие контакты и результаты в ответ кабинета не включаются. У пользователей с правом приглашать показано число ожидающих отправленных приглашений; у администратора учитываются приглашения всего сервиса.

В колонке настроек можно изменить своё имя и пароль, выйти из аккаунта. Школьник сохраняет полное ФИО (до 120 символов), отсутствие отчества и обязательный год выпуска вместе; остальные роли меняют обычное имя. Email показан только для чтения; роли и области изменяет администратор. API кабинета не принимает чужой ID, email или роли. Изменения личных данных пишутся в аудит; сохранение прежних значений не создаёт дополнительной записи.

Смена пароля требует текущий пароль, совпадающее подтверждение и проверки Django, включая минимум 12 символов. Текущий сеанс сохраняется; прежние сеансы утрачивают доступ при следующем запросе. Секреты не возвращаются и не попадают в аудит; событие содержит только тип действия и владельца. Оба изменения используют CSRF-защиту и требуют авторизованного пользователя. Эндпоинты: `GET/PATCH /api/account`, `POST /api/account/password`.


## Навигация школьника

У аккаунта только с ролью школьника в главном меню остаются «Кружки», «Личный кабинет» и «Мои результаты». Банки задач/листков и отдельная страница дерева тем скрыты; прямой переход на `#/problems`, `#/worksheets` или `#/topics` возвращает к кружкам, не монтируя эти страницы. На главной ссылка на банк заменена переходом к своим результатам, в кабинете — переходом к своим кружкам. Выданные листки, условия задач и разрешённые преподавателем решения по-прежнему открываются в кружке; банк для этого не требуется. Тематические данные личной аналитики сохраняются.

Совмещение ролей продолжает объединять права: при наличии роли преподавателя, аналитика или администратора соответствующие библиотечные разделы доступны. Изменение затрагивает навигацию и маршруты интерфейса; проверка доступа к материалам кружка и видимости решений на сервере остаётся обязательной.

## TeX и PDF в локальной демке

В редакторе задачи остаются обычные поля условия и решения; раскрываемый блок добавляет независимые необязательные TeX-фрагменты. Для каждой части используется TeX, если он задан, иначе обычный текст с экранированием специальных символов и сохранением встроенных формул `$…$`. TikZ подключён в шаблоне. Полные документы с собственной преамбулой в эти поля не вставляются.

У листка доступны предпросмотр и скачивание PDF: в банке, списке выдач кружка, блоках журнала, выборе листка и «Моих задачах». Таблицы аналитики содержат ссылки на PDF и загрузку. В общем банке отображаются заглушки даты, кружка и номера; в выдаче подставляются её реальные значения. Номер выдачи устойчив и не меняется при добавлении листка задним числом.

Предпросмотр по умолчанию показывает условия. Флажок «С доступными решениями» включает только разрешённые решения с исходными номерами задач. Преподаватель и администратор могут скачать тот же вариант как единый `.tex` или ZIP с шаблоном, переменными и отдельными файлами задач/решений. Школьник и аналитик получают PDF в своей области доступа; выгрузка исходников преподавательская. Скачанный ранее файл невозможно отозвать, текущая авторизация проверяется на каждый новый запрос.

## Фильтры пользователей и поиск школьников

«Пользователи и роли» доступен только администратору: пункт навигации, прямой маршрут и API проверяют это независимо. Поиск работает по ФИО/email, роли, состояние и годы выпуска выбираются множественно. Внутри одного фильтра — ИЛИ, между фильтрами — И. Вывод — по 30 аккаунтов со счётчиком и страницами; фильтры применяются сервером до ограничения выдачи. Поиск имён учитывает кириллицу, регистр, е/ё и перестановку частей ФИО.

В «Школьники → Добавить школьника» можно выбрать «По ФИО» или «По email». Для ФИО нужно минимум два символа; сервер выдаёт до 20 активных школьников с классом и замаскированным email. Уже состоящие в кружке отмечены и недоступны для повторного выбора. Выбор ещё не добавляет участника: перед сохранением показан выбранный школьник. При сохранении по его ID сервер повторно проверяет роль и активность; назначения старых листков и правила повторного вступления сохранены.

Новый школьник при принятии инвайта вводит полное ФИО и год окончания 11-го класса. Флажок «У меня нет отчества» позволяет зарегистрироваться без выдуманного отчества. Если зарегистрированный пользователь впервые получает роль школьника, он заполняет те же данные после входа под email получателя. Принятие нового инвайта уже зарегистрированным школьником не требует повторной регистрации. Ошибки остаются рядом с формой, введённые данные сохраняются для исправления.

Прежние сокращённые имена не заменяются вымышленными ФИО. В кабинете школьника есть подсказка заполнить профиль; форма сохраняет ФИО, наличие отчества и год выпуска вместе и больше не принимает вместо полного имени короткий псевдоним. Доступ существующих аккаунтов из-за неполноты старых данных не блокируется.

## Страница листка и личное пространство

Карточка в «Листках» открывает `#/worksheets/<document_id>`. Страница показывает автора, номер версии, личный/общий статус, темы, теги и упорядоченные задачи. Действия: автору — «Редактировать», читателям — «Скопировать себе», администратору — «Опубликовать для всех» для ещё не опубликованной текущей версии. Доступны предпросмотр PDF, скачивание и разрешённые исходники.

Список разделён на «Общая библиотека» и «Мои листки»; администратор также видит «Все личные листки». Поиск, теги и дерево тем работают внутри выбранного раздела. Школьнику доступно только личное пространство рядом с прежними «Моими задачами», где он может копировать полученные листки.

Редактор сохраняет личную новую версию, позволяет менять состав и порядок задач стрелками. Подсказки объясняют доступ администратора и сохранение уже выданных версий. Правки опубликованного листка помечаются до следующей публикации.

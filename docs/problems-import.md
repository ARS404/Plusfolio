# Задачи без названий и импорт problems.ru

Задача связана с листками, результатами, разборами и правами по UUID. Название необязательно и не участвует в сопоставлении. `ProblemNumber` выделяет отдельный постоянный номер средствами БД; он не меняется при поиске и сортировке. Неназванная задача показывается как «Задача №N». В API `title` содержит подпись для интерфейса, `custom_title` — исходное необязательное название. Листкам по-прежнему нужно название.

## Начальная подборка

В `data/problems_ru_sample.json` — 500 полных текстовых задач: 421 с развёрнутыми решениями, 79 с ответами без развёрнутого решения. В интерфейсе они различаются. Номера, ссылка problems.ru, темы, исходные классы/сложность и контрольная сумма сохраняются отдельно. Никакие названия не придумываются.

| Раздел | Задач |
| --- | --- |
| Логика и теория множеств | 139 |
| Алгебра и арифметика | 77 |
| Комбинаторика | 69 |
| Геометрия | 36 |
| Вероятность и статистика | 50 |
| Методы | 80 |
| Математический анализ | 49 |

Страницы с обязательными рисунками, табличными формулами, отсутствующим ответом или некорректной записью пропускаются целиком; текст не обрезается. HTML не исполняется и не отображается напрямую. Степени/индексы и формулы нормализуются в поддерживаемые математические фрагменты. В отчёте сохранены причины пропуска и SHA-256 загруженных страниц.

## Обновление и повторный импорт

```bash
python3 scripts/fetch_problems.py --limit 500
python3 scripts/fetch_problems.py --limit 500 --offline
.venv/bin/python backend/manage.py import_problems_ru data/problems_ru_sample.json --author admin@plusfolio.example --dry-run
.venv/bin/python backend/manage.py import_problems_ru data/problems_ru_sample.json --author admin@plusfolio.example
```

Укажите email действующего администратора вашего экземпляра. Сборщик использует штатные страницы по 100 задач с решениями, один запрос за раз, кэш и минимум 20 секунд между запросами согласно robots.txt. Сохранённый кэш позволяет продолжить загрузку; локальный импорт сам в сеть не обращается.

Уникальная пара `(source, source_id)` и детерминированный UUID по канонической ссылке исключают повторный импорт. Имеющиеся опубликованные задачи не перезаписываются; изменившийся текст источника приводит к отказу импорта. Пакет проверяется и применяется целиком в транзакции. Проверка `--dry-run` не изменяет БД.

Темы сопоставляются по исходным ID, переименования и переносы администратора сохраняются. Отсутствующие узлы создаются по сохранённому дереву вместе с дочерним «Прочее»; неизвестная дереву тема требует обновления каталога. Техническая тема problems.ru «Неопределено» отображается в корневое «Прочее», её оригинальный ID сохранён в метаданных. В этой подборке все содержательные темы уже были в каталоге.

Поиск в банке и выборе задач понимает номер Plusfolio, исходный номер problems.ru и UUID, а также название/условие. Основной банк разбит на страницы; выбор задач сохраняет прежний API списка.

## Источник и печать

Ссылка на problems.ru и исходный номер показываются в карточке, включаются в TeX/PDF и сохраняются при создании производной копии. Копия получает собственные UUID и номер и не становится второй записью импорта того же источника. Решения школьнику по-прежнему доступны только по прежним правилам раскрытия.

[Правила problems.ru](https://problems.ru/about_system.php) разрешают личное некоммерческое использование и использование на занятиях; при размещении на другом сайте требуют ссылку на problems.ru и номер задачи. Коммерческое использование требует отдельного согласования с проектом. Текущая подборка предназначена для локальной некоммерческой демки.

Tectonic остаётся закреплённым и минимальным. `scripts/setup_tex.py` дополнительно прогревает стандартные AMS-шрифты и вложенные индексы разных размеров на доверенном шаблоне. Пользовательские и импортированные исходники не передаются при прогреве; рабочая сборка остаётся без сети.


У каждой задачи есть ID Plusfolio вида `P-123` (локальный `number_id`). Он показывается в карточке и ищется точным запросом с префиксом, независимо от названия и номера problems.ru. Исходный номер и ссылка сохраняются отдельно.

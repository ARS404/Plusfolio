# История версий Plusfolio

## 1.0.0 — 31.10.2026

Первый релиз Plusfolio, тег `v1.0.0`.

- Кружки с несколькими преподавателями, составом, журналом и общими результатами школьников.
- Банк задач, личные и опубликованные листки с сохранением выданных редакций.
- Темы, теги, фильтры, аналитика и поиск по тексту и смыслу на CPU.
- Приглашения, роли, личный кабинет, документация и JSON API с токенами.
- TeX/TikZ, PDF, выгрузки, серверные образы с лимитами и зашифрованные бэкапы.
- Раздельное хранение БД и бэкапов, готовые образы и отдельный профиль ресурсов для пилота в Yandex Cloud.
- Повтор отправки готового бэкапа при сбое S3, независимая локальная ротация и очистка старых S3-версий.
- Логотип с плюсом на вкладке браузера.

Установка, обновление, резервное копирование и восстановление описаны в `docs/server-deploy.md`; результаты локального Linux-стенда — в `docs/pilot-capacity.md`. Приёмка на целевом сервере Yandex Cloud остаётся отдельным этапом.

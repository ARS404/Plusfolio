# История версий Plusfolio

## 1.0.0 — в разработке

Первый релиз готовится; стабильный тег `v1.0.0` пока не создан.

- Кружки с несколькими преподавателями, составом, журналом и общими результатами школьников.
- Банк задач, личные и опубликованные листки с сохранением выданных редакций.
- Темы, теги, фильтры, аналитика и поиск по тексту и смыслу на CPU.
- Потоковый расчёт аналитики с общими группами получателей и объединённые счётчики кабинета.
- Ускоренная выгрузка журнала Excel с повторным использованием оформления и чтением только нужных полей задач.
- Приглашения, роли, личный кабинет, документация и JSON API с токенами.
- Общая политика чтения решений для материалов, PDF и поиска; однократная обработка TeX и упрощённый запуск Compose v2.
- Общие типы тем и подписи ролей, индекс выбора тем, проекции поискового индекса и единый кодек конфигурации установки/восстановления.
- TeX/TikZ, PDF, выгрузки, серверные образы с лимитами и зашифрованные бэкапы.

Перед выпуском нужны проверка релиза и защищённый процесс обновления: остановка записи, обязательный проверенный бэкап и план восстановления. Версионирование само по себе не добавляет эти гарантии.
